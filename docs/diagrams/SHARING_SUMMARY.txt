================================================================================
CUSTOMIZATION EXAMPLES
================================================================================

Change Layout:
   direction="LR"  # Left to Right

Change Output Format:
   outformat="svg"  # Vector graphics
   outformat="pdf"  # PDF

Add AWS Service:
   from diagrams.aws.analytics import Kinesis
   kinesis = Kinesis("Stream")

Change Colors:
   Edge(color="red", style="bold")
